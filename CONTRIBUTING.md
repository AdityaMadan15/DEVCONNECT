# Contributing to DevConnect

Thanks for your interest in contributing! Please follow these guidelines to make collaboration smooth.

1. Fork the repository and create a feature branch named `feat/your-feature` or `fix/issue`.
2. Follow existing code style and formatting. The frontend uses modern React (hooks) and Tailwind CSS.
3. Run the app locally and ensure your changes work:

```bash
npm install
npm run dev:all
```

4. Add tests where appropriate (unit or integration).
5. Open a pull request with a clear description of changes and links to any related issues.
6. Keep PRs small and focused; we'll review and request changes if needed.

If your change requires DB migrations or other setup, include clear steps in the PR description.
